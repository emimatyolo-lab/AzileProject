# Azile Mhlophe – School of Legal Mastery

Information website for https://www.legalmastery.co.za (React + Vite, hosted on Netlify).

## Run locally
    npm install
    npm run dev

## Edit content
All text, prices, modules, WhatsApp number and social links live in `src/siteData.js`.

## Deploy
Pushing to `main` on GitHub auto-deploys on Netlify. Registration form submissions appear in Netlify → Forms.
